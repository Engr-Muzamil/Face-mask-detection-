😷 Face Mask Detection Using Deep Learning
📌 Overview

This project is a Face Mask Detection system built using Computer Vision and Deep Learning.
It can detect whether a person is wearing a face mask or not from:

Images

Video files

Live webcam feed

The model classifies faces into two categories:

✅ Mask

❌ No Mask

This project can be used in public places such as airports, hospitals, schools, and offices for safety monitoring.

🚀 Features

Real-time face mask detection

Works with images, videos, and webcam

High accuracy classification

Simple and easy-to-run code

Built with OpenCV + TensorFlow/Keras
